# Change Log

All notable changes to the "haokee-theme" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [2.0.4] - 2026-10-01

- Refined the Haokee Dark UI palette and editor hierarchy.
- Rebalanced Dark syntax colors for lower glare and better harmony.
- Unified parameter and macro coloring across semantic and TextMate scopes.

## [2.0.5] - 2026-10-01

- Increased visual separation between variables and functions in the Dark theme.
- Changed general variables to `#6EA8FF` and functions/methods to `#A8A2FF`.
- Kept semantic and TextMate token paths consistent.
